# Workflow records

Keep feature specs under specs/, detailed acceptance and evidence under tickets/, and decision maps under maps/. TODO.md remains the only task-state source.

Use one task branch and PR. Commit completed work before review. A cross-repository task has one linked TODO entry and one commit/PR in each affected repository.
