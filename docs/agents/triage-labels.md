# TODO category and state vocabulary

| Role | Allowed value | Meaning |
|---|---|---|
| Category | bug | Broken, unsafe, or contract-inconsistent behavior |
| Category | enhancement | New capability, test, maintenance, or refactoring |
| State | needs-triage | Scope, priority, or evidence needs review |
| State | needs-info | A missing fact blocks a safe specification |
| State | ready-for-agent | Acceptance is testable and implementation can start |
| State | ready-for-human | Physical access or a product decision is required |
| State | wontfix | Closed with a reason in TODO |

Each open task has exactly one category and one active state.
